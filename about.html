Data Sources

Live ClickHouse data sources from wspr.live, WsprDaemon WD1, and WsprDaemon WD2 are thankfully acknowledged. WSPRnet.org remains acknowledged as the original WSPR reporting network. These services should be used responsibly - according to reasonable use.

Destination Methods

Destination areas can be defined by City radius or by Map grids. City radius uses a selected city and endpoint radius. Map grids uses selected two-letter Maidenhead fields on the visual map. Both methods filter observed WSPR activity only; neither method claims propagation path direction.

Dependencies

The app is plain HTML, CSS, and JavaScript. It runs in a modern browser and does not require a server for local operation.

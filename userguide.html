User Guide

Basic Workflow

  1. Open WSPR Matrix.
  2. Enter the reporter callsign, UTC date, and local UTC offset if local time is wanted beside UTC.
  3. Choose Path 1 and Path 2 destination areas using continent, city, and radius.
  4. Select the live data server if live data will be used.
  5. Select up to 10 bands in the fixed toolbar.
  6. Press Refresh to collect live data and build the matrix, or press Load to build from one or more saved data files.
  7. Choose the counting mode: Raw Spots, Unique Beacons Per Bin, or Cumulative Unique Beacons.
  8. Use Save if you want to keep the collected JSON data for later review.
  9. Review the selected-path matrix and the all-beacons-heard matrix.
  10. Use Export CSV or Print / PDF for reports.

Fixed Toolbar

The fixed toolbar stays available while the matrix is being reviewed. It contains the high-use controls so the user does not need to scroll back to the top of the page.

  • Refresh collects live data for the entered callsign and UTC date, then rebuilds the matrix.
  • Save saves the current collected data as a JSON file.
  • Load opens saved JSON, CSV, HTML, or WSPRnet-style data files and builds the matrix. Multiple files can be selected together.
  • Clear clears the current matrix and collection state.
  • Counting cycles through Raw Spots, Unique Beacons Per Bin, and Cumulative Unique Beacons.
  • Green setup button opens or closes the callsign, date, and destination setup panel. Setup: Open shows the panel. Setup: Closed hides the panel and moves the matrix to its home position below the fixed toolbar.
  • Band buttons select the bands shown in the matrix. The counter shows how many bands are selected out of the maximum of 10.
  • Live data server selects the ClickHouse-compatible live source used by Refresh.
  • Request diagnostics opens details about live data requests and failures.
  • Export CSV saves the current matrix as a CSV file.
  • Print / PDF opens the browser print flow for paper or PDF output.
  • Row height changes matrix row spacing. This setting is useful when aligning two browser windows side by side.
  • Path radius controls adjust the endpoint radius for each selected path area.

Path Matrix and Global Matrix

Path matrix: the first matrix is filtered by the selected Path 1 and Path 2 destination areas. Destination filtering uses each beacon grid and the selected city radius.

Global matrix: the second matrix shows every beacon heard by the reporter callsign in the loaded or collected data. It is not filtered by Path 1 or Path 2.

Both matrices use the same toolbar counting mode and selected band buttons.

Counting Modes

Raw Spots counts every imported or collected report row.

Unique Beacons Per Bin counts each beacon callsign once within each 30-minute band/destination cell.

Cumulative Unique Beacons counts each beacon callsign once across the UTC day and shows the running total by time bin.

Using Saved Data

Use Load to import saved data and build the matrix. The old import panel is hidden because the Load button now performs that function.

Saved data can be collected JSON from this app or compatible WSPRnet-style files. When several files are selected together, exact duplicate rows are removed automatically.

Important Notes

  • JSON data should contain headers and rows, or an array of spot objects with reporter, date, band/frequency, grid, and callsign fields.
  • Blank cells mean no matching observed reports in the imported or collected data, not proof that propagation was closed.
  • Endpoint radius controls which beacon grids are included in each path area.
  • SNR is deliberately not used by WSPR Matrix.
